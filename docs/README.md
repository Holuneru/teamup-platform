# TeamUp — документация проекта

TeamUp — веб-платформа для студентов, которые ищут команду для стартапов, хакатонов, учебных и исследовательских проектов. Сейчас приложение включает профили пользователей, навыки, проекты и команды, заявки и приглашения, рекомендации участников, каталог хакатонов и каталог наставников.

Документация описывает код, обнаруженный в репозитории на ветке `master` при подготовке обновления в октябре 2026 года. Наличие эндпоинта не означает, что его бизнес-логика уже покрыта автоматическими тестами.

## Возможности

### Аккаунт и профиль
- регистрация и вход с использованием JWT;
- просмотр и редактирование собственного профиля;
- поиск и фильтрация пользователей по университету, навыку, роли и формату участия;
- загрузка аватара;
- редактирование навыков;
- настройка формата участия и признака поиска команды.

### Проекты и команды
- создание, просмотр, фильтрация и редактирование проектов;
- просмотр собственных проектов и проектов, в которых пользователь участвует;
- просмотр участников проекта и выход из проекта;
- подача заявок на вступление;
- приглашения в проект;
- рекомендации кандидатов на основе навыков и статуса поиска команды.

### Каталоги
- просмотр и управление каталогом хакатонов;
- фильтрация хакатонов по формату и дате;
- просмотр и управление каталогом наставников;
- отображение навыков наставников.

## Технологии

**Backend:** Java 21, Spring Boot 3.5.16, Spring Web, Spring Security, Spring Data JPA/Hibernate, Jakarta Validation, PostgreSQL, JWT (JJWT), Lombok, Maven.

**Frontend:** React 18, Vite, React Router, Axios, lucide-react, CSS.

## Архитектура

Backend использует слои Controller → Service → Repository → PostgreSQL. DTO отделяют формат HTTP-запросов и ответов от JPA-сущностей. Frontend находится в `frontend/`, backend и Maven wrapper — в корне репозитория.

## Запуск локально

Требуются JDK 21, PostgreSQL и Node.js, совместимый с используемой версией Vite.

1. Создайте локальную базу PostgreSQL.
2. Настройте параметры подключения и JWT secret в конфигурации приложения/переменных окружения. Не публикуйте реальные пароли и секреты.
3. Запустите backend из корня репозитория:

   ```bash
   ./mvnw spring-boot:run
   ```

   В Windows используйте `mvnw.cmd spring-boot:run`.
4. В отдельном терминале запустите frontend:

   ```bash
   cd frontend
   npm install
   npm run dev
   ```

Frontend настроен на локальный origin `http://localhost:5173`; CORS-конфигурацию нужно изменить для другого адреса. Проверьте фактические значения конфигурации перед запуском: параметры окружения могут отличаться на разных машинах.

## Проверка

- Backend: `./mvnw test`
- Frontend build: `cd frontend && npm run build`
- Frontend lint: `cd frontend && npm run lint`

Эти команды указаны как способы проверки; успешное выполнение в рамках обновления документации не подтверждалось. Следующий этап работ — добавить содержательные автоматические тесты и запускать эти проверки после изменений.
