# TeamUp

**TeamUp** — веб-платформа для поиска команды на хакатоны, стартапы, исследовательские и учебные проекты.

Платформа объединяет управление проектами, подбор участников по навыкам и взаимодействие внутри команды в одном приложении.

---

# Возможности

## Авторизация

- регистрация пользователей
- вход в систему
- JWT-аутентификация
- защищённые REST API
- безопасное хранение паролей (BCrypt)

---

## Профиль пользователя

Каждый пользователь может:

- редактировать личную информацию
- загружать фотографию профиля
- управлять своими навыками
- добавлять ссылки на Telegram и GitHub
- заполнять описание профиля
- выбирать предпочтительный формат участия
- указывать, находится ли сейчас в поиске команды

---

## Проекты

Пользователи могут:

- создавать проекты
- просматривать список проектов
- просматривать информацию о проекте
- управлять собственными проектами
- отправлять заявки на участие
- вступать в проекты по приглашению
- покидать проекты
- просматривать собственные проекты
- просматривать проекты, участниками которых являются

Каждый проект содержит:

- название
- описание
- владельца
- необходимые навыки
- список участников

---

## Поиск участников

Система поддерживает интеллектуальный подбор участников.

При рекомендации учитываются:

- совпадение навыков
- требования проекта
- готовность пользователя присоединиться к новой команде

В рекомендации попадают только пользователи, включившие статус **«Ищу команду»**.

---

## Заявки

Пользователь может отправить заявку на участие в проект.

Владелец проекта может:

- просматривать заявки
- принимать участников
- отклонять заявки

После принятия:

- пользователь автоматически становится участником проекта
- заявка закрывается

---

## Приглашения

Владелец проекта может приглашать пользователей напрямую.

Пользователь может:

- просматривать приглашения
- принимать приглашения
- отклонять приглашения

Система автоматически предотвращает повторные приглашения и удаляет конфликтующие заявки после вступления пользователя в проект.

---

## Навыки

Каждый пользователь формирует собственный стек навыков.

Для проектов указывается список необходимых технологий.

Эти данные используются системой рекомендаций при подборе участников.

# Архитектура

Backend построен по многослойной архитектуре.

```

Controller
↓
Service
↓
Repository
↓
Database

```

Для передачи данных между слоями используются DTO, что позволяет разделить внутреннюю модель базы данных и публичный API.

# Система рекомендаций

Алгоритм рекомендаций анализирует соответствие навыков пользователей требованиям проекта.

При расчёте учитываются:

- совпадение технологий
- статус поиска команды
- заполненность профиля

Полученный коэффициент используется для ранжирования кандидатов.

# REST API

Основные эндпоинты

```

POST   /api/auth/register

POST   /api/auth/login

GET    /api/users/me

PUT    /api/users/me

POST   /api/projects

GET    /api/projects

GET    /api/projects/{id}

GET    /api/projects/my

GET    /api/projects/participating

POST   /api/projects/{id}/apply

POST   /api/invitations/project/{projectId}/user/{userId}

GET    /api/invitations/me

POST   /api/invitations/{id}/accept

POST   /api/invitations/{id}/reject

```

```

├── Owner
├── Members
├── Required Skills
├── Applications
└── Invitations

```

# Безопасность

Система использует JWT-аутентификацию.

Пароли пользователей хранятся в виде BCrypt-хэшей.

Все защищённые запросы требуют передачи Bearer Token.
